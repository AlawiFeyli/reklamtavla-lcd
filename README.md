# reklamtavla-lcd
# Reklamtavla – IOT25 (Programmering för inbyggda system) Detta projekt är en lösning på inlämningsuppgiften "Reklamtavlan" i kursen *Programmering för inbyggda system* på Stockholms Tekniska Institut. Projektet simulerar en reklamskylt som visar olika kunders reklammeddelanden på en LCD‑display.
